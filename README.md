## How to Run

1. Install the Java Development Kit (JDK).
2. Clone this repository:

```bash
git clone https://github.com/Anusuyakav123/java-programming.git
```

3. Navigate to the repository folder.
4. Compile a Java program:

```bash
javac EvenOdd.java
```

5. Run the program:

```bash
java EvenOdd
```

Replace `EvenOdd` with the appropriate class name for other programs.
